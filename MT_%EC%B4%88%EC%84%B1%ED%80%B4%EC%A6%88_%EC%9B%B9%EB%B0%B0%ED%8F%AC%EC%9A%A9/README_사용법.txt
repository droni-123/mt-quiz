MT 초성퀴즈 PARTY — QR 실시간 참여형

[준비]
1. 윈도우 PC에 Python 3.10 이상을 설치합니다: https://www.python.org/downloads/
   설치할 때 'Add Python to PATH' 옵션을 선택하세요.
2. 이 폴더에서 '실행하기.bat'를 더블클릭합니다. (최초 실행시 인터넷으로 라이브러리 설치)
3. 검은 창에 표시된 '사회자' 주소를 PC 크롬/엣지 주소창에 입력합니다.
4. PC와 참가자 휴대폰을 같은 Wi-Fi 또는 같은 모바일 핫스팟에 연결합니다.
5. 사회자 화면 QR코드를 스캔하여 이름·팀을 선택 후 입장합니다.
6. 사회자가 문제 수와 시간 선택 후 게임 시작 버튼을 누릅니다.
7. 게임이 끝나기 전까지 검은 창을 닫지 마세요.

[점수와 진행]
- 모든 참가자가 동시에 스마트폰으로 정답을 입력합니다.
- 한 문제당 참가자별 2회 답안 기회. 띄어쓰기/영문 대소문자는 무시됩니다.
- 정답 선착순: 1등 100점, 2등 80점, 3등 60점, 이후 최소 40점.
- 첫 번째 제출에서 정답을 맞히면 +20점 보너스가 붙습니다.
- 팀 점수는 팀원들의 개인 점수 합산입니다.
- 시간 종료 시 자동 정답 공개. 사회자가 힌트/정답 공개/일시정지/다음 문제 제어.
- 사회자는 개인별 점수 ±50점 수동 조정 가능.
- 참가자가 새로고침하더라도 동일 브라우저라면 재접속됩니다.

[주의사항]
- 이것은 인터넷에 자동 공개되는 사이트가 아닌, 현장 PC에서 실행되는 로컬 웹사이트입니다.
- QR이 열리지 않으면 PC 방화벽에서 Python 허용, Wi-Fi 공유기의 기기 간 통신 차단(AP 격리) 해제 여부를 확인하세요.
- QR에 표시되는 주소는 실행 PC의 로컬 IP로 생성됩니다. PC의 Wi-Fi IP가 맞지 않는다면 실행 전 LAN_IP 환경변수를 설정하세요.
- 외부 인터넷에서도 접속하려면 별도 서버/호스팅 및 HTTPS 설정이 필요합니다. 외부 공개 시 참가자 인증과 보안 설정도 추가해야 합니다.
- 한 대의 PC로 여러 참가자 동시 접속 시 Wi-Fi 품질에 영향을 받습니다.
- 진행 중 서버를 종료하면 참가자 점수/게임 상태가 초기화됩니다.
- 사회자 PIN이 포함된 전체 URL은 참가자에게 공개하지 마세요.
