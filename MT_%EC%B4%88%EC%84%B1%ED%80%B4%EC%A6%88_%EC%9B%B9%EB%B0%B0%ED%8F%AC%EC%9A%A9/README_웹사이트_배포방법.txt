MT 초성퀴즈 — 인터넷에서 QR로 참여하는 방법

[웹사이트 공개하기: GitHub + Render]
1. GitHub(github.com)에 로그인 후 New repository를 만들고 Public 또는 Private로 설정합니다.
2. 이 폴더 안의 파일 5개(server.py, index.html, requirements.txt, render.yaml, 실행하기.bat 등)를 저장소 최상위에 업로드하고 Commit합니다.
3. Render(render.com)에 가입/로그인 후 GitHub 계정을 연결합니다.
4. Render에서 New > Blueprint 를 선택하고 이 저장소를 연결합니다.
5. render.yaml 설정을 확인하고 배포합니다. 무료 플랜 선택 가능 여부는 계정/정책에 따라 달라집니다.
6. 배포 완료 후 제공된 https://...onrender.com 주소를 방문합니다.
7. 사회자 전용 주소는 Render Dashboard > 해당 서비스 > Logs에서 '사회자:' 다음에 나온 URL을 복사합니다. PIN이 포함되어 있으니 비밀로 하세요.
8. 사회자 페이지의 QR을 띄우면 참가자는 자기 휴대폰 데이터나 와이파이로 접속할 수 있습니다.

[주의]
- Render 서비스가 절전/재시작하면 대기시간이 생기거나 진행 중 점수가 초기화될 수 있습니다. 모든 데이터는 서버 메모리에 저장됩니다.
- 행사 전에는 직접 여러 휴대폰으로 입장/답변 테스트를 꼭 하세요.
- 무료 플랜 사용 가능 조건, 동시접속 성능, 사용량 제한은 호스팅 제공업체의 최신 정책을 확인하세요.
- Render에 여러 인스턴스를 띄우면 서버 간 점수가 동기화되지 않으므로 한 인스턴스로 실행하세요.
- 공개된 링크를 아는 사람이 입장할 수 있으므로 팀/닉네임을 확인하고 외부 배포에 주의하세요.

[로컬 실행 방식]
동일 Wi-Fi 기반 진행을 원한다면 실행하기.bat 사용, Python 설치 필요.
